Our Mission

Deliro aims to create an independent cryptocurrency network where the rules are public, the software is open-source, and anyone can independently verify the blockchain.

Important project status:
Deliro is currently in development. The blockchain has not launched. No live mining, market price, or network statistics are being claimed.

Our Principles

No Premine

The proposed design has no founder allocation or premine.

Open Source

The goal is publicly available code that anyone can inspect and verify.

Public Ledger

Transactions and network rules should be independently verifiable.

No Central Control

No founder should have unilateral power to change consensus rules or confiscate coins.

Proposed Protocol

SHA-256d Proof of Work

Halving

Every 210,000 blocks (proposed)

These are draft parameters, not finalized consensus rules. They require technical specification, implementation and independent testing.

Mining & AuxPoW

Deliro is designed to investigate SHA-256d Auxiliary Proof of Work (AuxPoW), which may allow compatible Bitcoin mining pools to mine DEL alongside Bitcoin.

Merged mining requires explicit pool support and valid proof verification. It does not automatically provide Bitcoin's full security to Deliro.
